## About me

Backend Engineer @ [Uphold](https://uphold.com/), based in Portugal. I design and build distributed backend systems with an emphasis on resilience, observability and maintainability, and my security background lets me look at software the way an attacker would.

Outside of work I run a self-hosted [homelab](#-homelab), which is my playground for systems design, orchestration and overall experimentation and research and I write about it all on [my website](https://joaoguedes.net). Feel free to check it out!

## Focus areas

- **Backend & distributed systems**: architecture, workflows, system design and programming
- **Application security & Penetration Testing**: secure SDLC, vulnerability research, exploit analysis and reverse engineering
- **Platform & DevOps**: orchestration, CI/CD, infrastructure and self-hosting

## Work in Progress

- Growing and iterating [joaoguedes.net](https://joaoguedes.net)
- AR mobile monster-capturing game (Invizimals-inspired)
- Go-based media player
- Wii Sports memory analysis + code injection mod
- 2D PSP game with [pspdev](https://pspdev.github.io/)

## Homelab

Outside of work I run a small homelab on Proxmox with LXC containers and a ZFS mirror, treated like a tiny production environment. It's where I practise systems design, security and operations, system administration and host all my personal services.
